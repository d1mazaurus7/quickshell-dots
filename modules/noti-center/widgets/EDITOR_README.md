# Редактор виджетов центра уведомлений

Кнопка с карандашом в правом верхнем углу центра включает режим редактирования,
галочка — выключает. При закрытии центра режим сбрасывается.

## Для пользователя

- **Перестановка** — зажать виджет и тянуть; остальные плавно сдвигаются.
  Отпустить за последним виджетом — переместить в конец.
- **Размер** — тянуть ручку на правом крае (ширина), нижнем (высота) или в углу (оба).
  Ручки появляются при наведении на край обводки (курсор меняется на стрелки).
  Размер прилипает к ячейкам сетки и ограничен пределами виджета.
- **Удалить** — крестик (цвет tertiary) на скруглении правого верхнего угла.
- **Добавить** — чипы под сеткой (виджеты, которых сейчас нет).
- Изменения сохраняются сразу после отпускания мыши.

## Устройство

| Файл | Роль |
|---|---|
| `controls/WidgetGrid.qml` | раскладка, отрисовка, перетаскивание, масштабирование, лоток |
| `controls/ResizeHandle.qml` | ручка края |
| `LayoutState.qml` | `ListModel` ⇄ `Config.options.notiCenter.layout` |
| `widgets/Registry.js` | каталог виджетов и раскладка по умолчанию |

### Данные

`notiCenter.layout` — `[{ type, w, h }]`, порядок = порядок чтения; `null` — `Registry.defaults`.
`LayoutState.load()` отбрасывает неизвестные типы и дубли, ограничивает размеры
пределами из реестра. Модель меняется на месте (`move`, `setProperty`, `append`, `remove`),
поэтому виджеты не пересоздаются; полная перезагрузка — только при внешнем изменении конфига.

### Раскладка

`WidgetGrid.relayout()` — последовательная упаковка: каждый виджет ставится
в первое свободное место не раньше предыдущего. Результат — `rects[index] = { c, r, w, h }`
в ячейках; пиксели: `x = c·stepX`, `width = w·stepX − gap`. Пересчёт — на сигналы модели.

### Перетаскивание

- Делегат на время переноса берёт позицию у курсора (`dragging`, `dragX/Y`), остальные —
  из `rects` с анимацией `Emphasized`.
- `dragTo(from, p)` — найти виджет под курсором и `model.move(from, target)`.
- `blocked` — гистерезис: с только что сдвинутым виджетом обмен не повторяется,
  пока курсор его не покинет (иначе виджеты разной ширины дрожат).
- На отпускании — `edited()` → `LayoutState.save()`.

### Обводка

Обводка строится вокруг видимой формы виджета: зазор `pad` (3·s) + толщина `bw` (2·s),
скругление = `editRadius + pad + bw`. Форму виджет сообщает свойствами `editInsetV`, `editRadius`
(по умолчанию — вся ячейка и скругление плитки). Ручки краёв лежат на линии обводки,
угловая ручка и крестик — на дуге скругления под 45°.

### Масштабирование

`resizeAt` переводит курсор в число ячеек `round((p − home + gap) / step)`,
`resizeTo` ограничивает его пределами из реестра и числом колонок.

### Оптимизация

- Рамка редактора — `Loader`, активен только в режиме редактирования (и на время затухания).
- Анимации делегата включаются после первого размещения (`settled`), у переносимого —
  выключены.
- `missing` (лоток) переприсваивается только при изменении набора типов.
- Содержимое виджета в редакторе отключено (`enabled: false`), события не обрабатываются.

### Расширение

- Колонки — `WidgetGrid.columns`, высота строки — `rowHeight`, зазор — `gap`.
- Новое действие редактора — в `sourceComponent` рамки делегата в `WidgetGrid.qml`;
  после изменения модели вызвать `grid.edited()`.
