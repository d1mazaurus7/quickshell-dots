# FlowHighlight — анимация выделения текущего элемента списка

## Описание

`FlowHighlight` — переиспользуемое выделение для `ListView`/`GridView`. Оно "перетекает" от старого элемента к новому (передняя грань обгоняет заднюю), слегка увеличивается (`selectedScale`) и при необходимости плавно прокручивает список, чтобы текущий элемент оказался в видимой области.

`FlowHighlightAnimation` — синглтон с общими настройками (цвет, длительность, радиус, прозрачность, масштаб, плавная прокрутка).

## Файлы

- `FlowHighlight.qml` — компонент выделения
- `FlowHighlightAnimation.qml` — синглтон с настройками
- `FlowHighlightExample.qml` — пример
- `qmldir` — регистрирует оба типа

## Подключение

```qml
import "../" as Flow        // путь до директории, где лежит qmldir

ListView {
    id: list
    model: ...
    highlight: Flow.FlowHighlight { view: list }
    delegate: ...

    Keys.onDownPressed: currentIndex = Math.min(currentIndex + 1, count - 1)
}
```

Больше ничего не нужно. `FlowHighlight` сам:

- выставляет `highlightFollowsCurrentItem: false`;
- следит за `currentItem` и перетекает к нему;
- прокручивает список (`contentY`) синхронно с выделением.

Если в списке уже есть собственные вызовы `positionViewAtIndex(...)`, их лучше убрать — прокруткой занимается компонент. Если оставить, выделение всё равно отработает без рывков, но прокрутка будет мгновенной.

## Как устроена плавность у границы

Анимация считается в координатах окна просмотра, а не содержимого: у границы списка выделение стоит на месте, а элементы едут под ним. Поэтому нет "отскока" вверх-вниз, который возникал, когда выделение и прокрутка двигались независимо. Положение цели обновляется на лету, так что смена геометрии делегата или прокрутка во время анимации не ломают траекторию. При быстром повторном переключении (удержание клавиши) анимация продолжается с текущей позиции.

## Параметры

Значения по умолчанию берутся из `FlowHighlightAnimation` и могут быть переопределены у конкретного `FlowHighlight`:

- `view` — список (обязательный)
- `highlightColor` — цвет (по умолчанию `Theme.Palette.primary`)
- `animationDuration` — длительность, мс (200)
- `highlightRadius` — радиус скругления (8)
- `highlightOpacity` — прозрачность (0.3)
- `selectedScale` — увеличение выделения (1.04)
- `smoothScroll` — плавная прокрутка к текущему элементу (true)

Изменение общих настроек:

```qml
FlowHighlightAnimation.updateSettings(color, duration, radius, opacity, scale) // undefined — не менять
```

## Ограничения

- Увеличивается сама подсветка, а не содержимое делегата.
- Подсветка рисуется под делегатами; делегаты с непрозрачным фоном её закроют.
- Прокрутка — только вертикальная.
